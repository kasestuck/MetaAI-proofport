it changes. Proofport helps answer that question. I built this prototype during

## Short project description

Proofport is a local Python/PHP modernization console that verifies Meta Muse
Spark proposals against original behavior in Docker. It combines golden-case
comparison, existing tests, security rescans, immutable originals and chained
evidence. Genuine Python and PHP module migrations passed their recorded checks;
a real security proposal was rejected rather than silently accepted after behavior
changed. Saved demonstrations are explicitly labelled replay.

## Recording guardrails

- Keep the saved-run badge visible. Say “saved real run” before each migration.
- Never imply P10 made another Meta call or that an AI Fix Loop ran in the two
  successful one-call migrations.
- Do not call all warnings exploitable vulnerabilities, or all projects compatible.
- No API key/account settings/private notifications in frame.
- If navigation takes longer, shorten narration; do not accelerate the footage
  to imply a faster model run. Measure the exported video's actual duration.
- Final English voiceover, video URL and signed-out playback checks are owner tasks.
